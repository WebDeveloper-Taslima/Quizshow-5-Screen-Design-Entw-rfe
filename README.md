---

## 🎬 Screen Designs Overview

1. **Screen 01 - Smartphone Live App Interface**
   - Smartphone controller UI featuring right-aligned burger menu, qualification badge, 4 data metrics (Points 512, Play Time 00:41:22, Rank 142, Coins 200c), 28s linear progress countdown, answer buttons A-D with film reel icons, and interactive **Banger** (2x points) & **Joker** (50:50) highlight buttons.
2. **Screen 02 - Moderator & Leaderboards (Top 20 / Top 50)**
   - Futuristic voxel AI Moderator avatar with voice visualizer waves, "Welt der Wunder - Top 20" podium highlights (Gold #1, Silver #2, Bronze #3), and "Zwischenstand Top 50" overall standings container with rank change trend indicators (`▲`, `▼`, `-`).
3. **Screen 03 - Quiz Announcement & 10s Countdown**
   - Widescreen 3D metallic ice-crystal "10" numeric countdown digits, round metadata (`Runde #02 / 06`), quiz title *"Die Welt des Films"*, and "Zwischenstand Top 20" candidate standings.
4. **Screen 04 - Creator Video Question HUD**
   - Creator video frame featuring presenter *LillyWunderbar* with verified badge, glassmorphism HUD overlay, 28s linear progress countdown bar, question counter, and film reel answer pills.
5. **Screen 05 - Winners Podium & Final Standings**
   - 3D spotlight podium stage showcasing Top 3 Champions (Rank 1 center elevated Gold, Rank 2 Silver, Rank 3 Bronze), Top 10 feature list, Plätze 11-30 grid, top right timer badge (*"Weiter geht's in 00:00:42"*), and bottom stage banner.

## 🌐 Live GitHub Pages Deployment Guide

To deploy this interactive client presentation as a live web link on **GitHub Pages**:

1. Push this repository to GitHub.
2. Go to your repository **Settings** tab.
3. Click on **Pages** in the left sidebar menu.
4. Under **Build and deployment** -> **Branch**, select `main` (or `master`) and folder `/ (root)`.
5. Click **Save**. Your live link will be generated in 1-2 minutes!
